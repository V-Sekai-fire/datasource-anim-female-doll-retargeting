# datasource-anim-female-doll-retargeting

A game-engine project that retargets dance and walk animations onto a set of humanoid avatars, the female doll among them.

## What it is for

It holds the avatar models, the animation clips, the bone maps from each skeleton to a shared humanoid profile, and scenes that play a retargeted clip on each avatar. The editor add-ons arrive as git submodules.

## Build and run

```sh
git submodule update --init
```

Then open `project.godot` in the engine's editor.
